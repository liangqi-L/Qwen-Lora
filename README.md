# 基于大模型微调的金融新闻情绪分类项目

这个项目的目标是：

1. 读取金融新闻数据
2. 把数据转换成适合大模型微调的格式
3. 微调一个中文大模型
4. 让模型输出 `利好`、`中性`、`利空`
5. 对模型结果做评估

第一阶段我们先只做最基础的准备工作：

1. 新建项目目录
2. 定义标签集合
3. 定义原始数据格式

后面再继续写训练、预测和评测脚本。

# 名词解释：
LoRA 是 Low-Rank Adaptation，中文常说“低秩适配”。它是一种参数高效微调方法：不是把整个大模型都重新训练一遍，而是冻结原模型的大部分参数，只额外训练一小组很小的参数矩阵，让模型适应你的任务。原始论文就是这样定义的。
